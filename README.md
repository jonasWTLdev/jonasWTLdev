- Business-time handling with timezone and DST coverage
- Architecture guards, Vitest suites and dual-runtime smoke tests

### ChatGPT Font Switcher

A lightweight **Manifest V3** browser extension for changing fonts on ChatGPT and other webpages.

**Highlights**
- Chrome / Microsoft Edge compatible
- Font selection from a popup
- Live preview
- Apply and reset controls
- Saved preferences with `chrome.storage.sync`
- Optional font application to code blocks
- Can run across normal webpages

### Local LLM + Ollama

Exploration and documentation of a **privacy-first, on-premise LLM setup** for processing and summarizing reports.

`Browser / Client` → `HTTPS` → `Node.js Backend` → `Ollama on VM`

Focus areas include:
- Data sovereignty and privacy
- VM-hosted local models
- Report summarization
- Secure backend-to-model communication
- Maintainability and resource requirements

## ↗ How I Work

- Build the useful thing first.
- Keep frontend and backend responsibilities clear.
- Prefer explicit contracts over hidden coupling.
- Test important behavior before calling a feature finished.
- Automate repetitive work.
- Keep privacy and data ownership in mind.
- If the right tool does not exist: **make it urself.**
